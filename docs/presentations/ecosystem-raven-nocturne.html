The Problem

Why AI agents need infrastructure

Current State

Agents Start From Zero, Every Time

  • Every new session erases all learned context and decisions
  • Agents repeat the same mistakes across projects and sessions
  • Skills are installed manually with no relevance matching
  • No feedback loop: successes and failures vanish at session end
  • Manual task routing wastes time picking the right agent type
02

The Ecosystem

Two systems, one feedback loop

Memory & Learning

Quoth

Self-learning platform that captures agent trajectories, distills patterns, and injects high-confidence knowledge into future sessions.

  • 9 hook bindings, 22 MCP tools
  • 3-stage LLM pipeline (JUDGE, DISTILL, CONSOLIDATE)
  • Bayesian confidence scoring with Thompson sampling
  • Unified injection: patterns + docs ranked together

Knowledge Curation

Skill Registry

Centralized skill management that matches, forks, and AI-rewrites skills per project context.

  • Semantic search via pgvector (1536d embeddings)
  • Per-project fork & AI rewrite pipeline
  • MCP server + REST API (Hono)
  • Quoth patterns feed optimization queries

Skill Registry: Knowledge Curation

The right skills for every project

Skill Management

Centralized, Versioned, Intelligent

Semantic Search

pgvector HNSW with 1536d embeddings. Find skills by meaning, not just keywords.

Per-Project Forks

Fork any skill and scope it to a project. AI rewrites content using project context.

Jinja2 Templates

Skills can be markdown or Jinja2 templates with dynamic variables per agent.

Drift Detection

Detect when base skills change after fork. Re-optimize without losing customization.

Agent Binding

Skills assigned to agents (OpenClaw, Claude Code, Quoth). Resolved via MCP at runtime.

Skill Groups

Bundle related skills into installable groups. One command, full stack coverage.

Integration Point

Quoth Patterns Feed Skill Optimization

optimize.ts 
// Quoth patterns become semantic search queries
function buildSearchQueries(ctx, quothPatterns) {
  const queries = []

  // Tech stack queries
  for (const tech of ctx.techStack)
    queries.push(`${tech} best practices`)

  // Quoth-learned behavior drives discovery
  for (const p of quothPatterns.slice(0, 5))
    queries.push(p.description.slice(0, 200))

  return [...new Set(queries)]
}
