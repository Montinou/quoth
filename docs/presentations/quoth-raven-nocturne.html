The Problem

Why AI agents need persistent memory

Current State

Agents Start From Zero

  • Every new session erases all learned context and decisions
  • Agents repeat the same mistakes across sessions
  • No way to share knowledge between team agents
  • Manual task routing wastes time picking the right agent type
  • Valuable patterns from successful workflows are lost forever
02

The Solution

What Quoth does differently

Overview

A Two-Tier Learning System

Quoth combines a local Claude Code plugin with a cloud SaaS platform to give agents persistent, cross-session memory that improves automatically over time.

Trajectory Capture

Every tool call automatically logged. Zero-friction, hook-based. Builds raw data for pattern extraction.

Pattern Learning

3-stage LLM pipeline (Judge, Distill, Consolidate) extracts reusable patterns with Bayesian confidence.

Intelligence Routing

PageRank graph + keyword matching routes tasks to optimal agent types automatically.

Pattern Injection

Top patterns injected at session start and subagent spawn. Agents begin with institutional knowledge.

Local Mode

Full Privacy

  • All processing on your machine
  • SQLite + HNSW vector index locally
  • Gemini 2.5 Flash for Judge (batch 30) & Flash Lite for Distill
  • Claude Haiku 4.5 for Consolidation
  • MiniLM-L6-v2 embeddings (384d, local, $0)

Managed Mode

Cloud Power

  • Pipeline runs in the cloud
  • Neon PostgreSQL + pgvector
  • Team pattern sharing
  • Cross-project knowledge sync
  • Just needs a qth_* API key

Automation

8 Hook Events

Zero-friction automation. Every hook fires without user intervention.

  • UserPromptSubmit — route task + inject patterns
  • SessionStart — restore intelligence graph
  • PostToolUse — capture trajectory data
  • SubagentStart — inject domain patterns
  • SessionEnd — consolidate + recompute PageRank
04

Intelligence & Routing

How Quoth picks the right agent for every task

Intelligence Graph

Task Routing Engine

Combines keyword pattern matching with PageRank graph analysis to route tasks to the optimal agent type.

8 Agent Types

Coder, Tester, Reviewer, Researcher, Architect, Backend Dev, Frontend Dev, DevOps — each with capability mappings.

PageRank Scoring

Graph-based importance ranking across agent capabilities. Recomputed at session end for accuracy.

Bilingual Patterns

English + Spanish keyword pattern library for task classification. Extensible regex-based matching.

Confidence Routing

Bayesian Beta(a,b) scoring. Only patterns with ≥0.6 confidence injected. Top 3 per session.

  https://quoth.triqual.dev/api/mcp

# Full plugin (recommended)
cd quoth-plugin && bash scripts/setup.sh

# Interactive onboarding
node quoth-plugin/scripts/cli.js init

# Check daemon status
quoth_daemon_status

Cloud Platform

Multi-tenant SaaS with team collaboration

Cloud SaaS

Enterprise-Ready Knowledge Hub

Built on Next.js 16 with Clerk auth, Neon PostgreSQL, and Vercel infrastructure.

Multi-Tenant

Organization isolation via Clerk + Row-Level Security. Role-based access: Admin, Editor, Viewer.

Knowledge Base

Semantic search across project docs with pgvector HNSW indexes. Chunk-level retrieval.

Team Patterns

Share patterns across your org. Proposal workflow for pattern updates with evidence tracking.

Genesis Bootstrap

Auto-scan codebase and generate documentation. One-command project onboarding.

Agent Coordination

Inter-agent messaging, task assignment, and inbox system via the comms schema.

Observability

Braintrust + Vercel OTEL for LLM call tracing. Usage analytics and speed insights.
