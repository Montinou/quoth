The Problem

Agents Start From Zero, Every Time

No Memory

Every session erases all learned context. Agents repeat the same mistakes across projects.

No Feedback Loop

Successes and failures vanish at session end. No way to learn from outcomes.

Manual Skill Selection

Skills installed manually with no relevance matching. No optimization per project.

Memory & Learning

Quoth

Self-learning platform that captures agent trajectories, distills patterns, and injects high-confidence knowledge.

  • 9 hook bindings, 22 MCP tools
  • 3-stage LLM pipeline (JUDGE → DISTILL → CONSOLIDATE)
  • Bayesian scoring with Thompson sampling
  • Unified injection: patterns + docs ranked together
  • Graded reward signal (0.0 – 1.0)

Knowledge Curation

Skill Registry

Centralized skill management that matches, forks, and AI-rewrites skills per project context.

  • Semantic search via pgvector (1536d)
  • Per-project fork & AI rewrite pipeline
  • MCP server + REST API (Hono + Bun)
  • Quoth patterns feed optimization queries
  • Drift detection for stale forks

Agent Types

Self-Healing

  • Exception handling — daemon never crashes
  • Stale lock auto-cleanup from previous crashes
  • HNSW rebuild from DB on corruption
  • Exposure-based decay (30d archive, 600 cap)
  • Stale session detector (10min, synthetic summaries)
  • Auto doc maintenance (nightly hash scan + LLM update)

Graceful Degradation

  • Gemini API down → Outcome-based judging
  • Embedding model fail → Keyword matching
  • Cloud unavailable → Local learning continues
  • Redis unavailable → Rate limiting disabled
  • Reranker down → Vector similarity order
