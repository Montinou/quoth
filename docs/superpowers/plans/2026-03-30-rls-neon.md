# Neon RLS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Enable Row Level Security on all Neon tables so data isolation is enforced at the database level — zero-trust, not just application-layer filtering.

**Architecture:** Use PostgreSQL session variables (`SET LOCAL`) to pass `org_id` from Clerk auth context to the database. RLS policies use `current_setting('app.org_id')` to filter all queries automatically. The unpooled connection handles `SET LOCAL` per-request. Tables without direct `org_id` use JOIN-based policies.

**Tech Stack:** Neon PostgreSQL, Drizzle ORM (unpooled for RLS), Clerk JWT claims

---

## Strategy

### Session Variable Approach

Every authenticated request does:
```sql
SET LOCAL app.org_id = '<uuid>';
SET LOCAL app.user_id = '<clerk-user-id>';
```

Then RLS policies check:
```sql
CREATE POLICY org_isolation ON public.projects
  USING (org_id::text = current_setting('app.org_id', true));
```

### Connection Model

- **Current:** `getDb()` returns pooled connection (no session state)
- **Change:** Create `getSecureDb(orgId, userId)` that uses unpooled + SET LOCAL
- **Cron/webhook routes:** Use a service role that bypasses RLS (no session vars)

### Table Categories

| Category | Tables | RLS Strategy |
|----------|--------|--------------|
| **Direct org_id** | organizations, projects, agents.registry, agents.api_keys, agents.memory, agents.webhook_subscriptions, comms.channels, comms.messages, comms.tasks, analytics.activity | `org_id = current_setting('app.org_id')` |
| **Via project FK** | project_members, agents.agent_projects, docs.documents, docs.proposals, docs.chunks, search.*, analytics.coverage/usage/generations | JOIN to projects for org_id |
| **Via org FK** | org_members, comms.channel_subscriptions, comms.webhook_deliveries | JOIN through parent |
| **No scoping needed** | users (global, Clerk-managed) | Read-only policy, users see only self |

-- Migration 005: Enable Row Level Security
-- All tables get RLS. Policies use session variables set per-request.
-- Service role (used by crons/webhooks) bypasses RLS.

-- ============================================================================
-- Helper: safe current_setting that returns NULL instead of error
-- ============================================================================

CREATE OR REPLACE FUNCTION app_org_id() RETURNS uuid AS $$
  SELECT NULLIF(current_setting('app.org_id', true), '')::uuid;
$$ LANGUAGE sql STABLE;

CREATE OR REPLACE FUNCTION app_user_id() RETURNS text AS $$
  SELECT NULLIF(current_setting('app.user_id', true), '');
$$ LANGUAGE sql STABLE;

-- ============================================================================
-- PUBLIC SCHEMA
-- ============================================================================

-- organizations: users can only see orgs they belong to
ALTER TABLE public.organizations ENABLE ROW LEVEL SECURITY;
CREATE POLICY org_member_access ON public.organizations
  USING (id = app_org_id());

-- org_members: scoped to current org
ALTER TABLE public.org_members ENABLE ROW LEVEL SECURITY;
CREATE POLICY org_member_isolation ON public.org_members
  USING (org_id = app_org_id());

-- users: users can see members of their org
ALTER TABLE public.users ENABLE ROW LEVEL SECURITY;
CREATE POLICY user_org_access ON public.users
  USING (
    id IN (SELECT user_id FROM public.org_members WHERE org_id = app_org_id())

## Phase 2: Secure DB Connection Wrapper

### Task 2: Create getSecureDb() function

**Files:**
- Modify: `src/db/connection.ts`

- [ ] **Step 1: Add getSecureDb()**

```typescript
/**
 * Get a database connection with RLS session variables set.
 * Uses unpooled connection to support SET LOCAL.
 * Call this from all authenticated API routes.
 */
export async function getSecureDb(orgId: string, userId?: string) {
  const db = getUnpooledDb();

  // Set session variables for RLS policies
  await db.execute(sql`SET LOCAL app.org_id = ${orgId}`);
  if (userId) {
    await db.execute(sql`SET LOCAL app.user_id = ${userId}`);
  }

  return db;
}
```
