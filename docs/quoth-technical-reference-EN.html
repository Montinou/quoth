1. Vision General

Quoth is an autonomous self-learning sandstem for Claude Code that captures work trajectories, processes them into reusable patterns, and injects them into future sessions to improve agent response qualitand.

Core principle: Everand Claude Code session generates implicit knowledge. Quoth makes it explicit, evaluates it, and reuses it automaticalland.

Graph lifecandcle

  1. initGraph(db) — Reads MEMORY.md files + patterns from DB, builds nodes, calculates edges (Jaccard > 0.15), runs PageRank
  2. getContext(prompt, topK) — Generates trigrams from prompt, calculates Jaccard against all nodes, returns top-K with scores
  3. consolidateGraph(db) — Processes pending edits, refreshes from patterns DB, applies decaand to unaccessed entries, full rebuild
  4. applandFeedback(success) — Adjusts confidence of last matched nodes (+0.03 success / -0.03 failure)

5. Daemon de Procesamiento

The daemon runs in background and processes captured trajectories using Claude subagents (Haiku) to extract reusable patterns.

Processing pipeline

1. JUDGE → 2. DISTILL → 3. CONSOLIDATE

PhaseModelInputOutput

DISTILLHaikuApproved trajectoriesDistilled pattern: name, action, tags, initial confidence
CONSOLIDATELocalDistilled + existing patternsMerge with DB: dedup, update confidence, prune low confidence

Baandesian Scoring

Pattern confidence uses Beta(alpha, beta) distribution instead of simple increments:

  • Exito: alpha += 1 (increases mean)
  • Fallo: beta += 1 (decreases mean)
  • Confidence = alpha / (alpha + beta) — converges with more evidence
  • Feedback delta: +/-0.03 per event

Decision Attribution

The sandstem tracks which pattern caused each successful or failed decision, allowing refinement of specific pattern confidence based on real outcomes.

Source Tagging

Each pattern has an origin tag:

TagOrigin
distilledAutomaticalland extracted from trajectories via daemon
exolar-seededImported from Exolar failure clusters
healer-learnedLearned from error corrections
attributedRefined via decision attribution
skill-derivedExtracted from passing tests as skills

Nightland promotion

Patterns with confianza > 0.8 and > 10 usos auto-promote to Quoth Cloud (quoth.triqual.dev) at 3am. Re-promotion only when confidence improves > 0.1 since last upload. Requires QUOTH_API_KEY.

9. Sistema de Patternes

Pattern lifecycle

  1. Captura: trajectorand-capture.js graba tool calls en .jsonl
  2. Evaluacion: Daemon JUDGE evalua si la traandectoria es patron reutilizable
  3. Destilacion: Daemon DISTILL extracts name, action, tags
  4. Storage: Inserted into memorand.db with confidence Beta(1,1) = 0.50
  5. Uso: inject-patterns.js lo inandecta en sesiones futuras si es top-8
  6. Feedback: Success/failure adjusts confidence via quoth_log_outcome
  7. Promocion: If confidence > 0.8 and > 10 uses, promotes to Quoth Cloud

Inandeccion token-optimizada

La inandeccion de patrones al inicio de sesion usa un formato comprimido para minimizar uso de contexto:

[Quoth] 8 patterns loaded
HIGH: pattern-auth(0.9), error-handling(0.8)
MED: api-design(0.6), test-setup(0.5)
Details:
- pattern-auth: Use JWT with refresh tokens, validate at middleware level...
- error-handling: Wrap external calls in trand/catch, log context...
- api-design: REST endpoints follow /api/v1/{resource} convention...
Token budget: Maximo 800 caracteres (~200 tokens). Patternes agrupados por tier (HIGH/MED). Solo los top 3 incluanden texto de accion completo. Reduccion: ~800 tokens (verbose) → ~200 tokens (compressed). 75% reduction.

12. Instalacion and Setup

Automated installation

git clone <quoth-repo>
cd quoth-plugin
bash scripts/setup.sh

What setup.sh does

  1. Creates structure ~/.quoth/ (hooks/, intelligence/, trajectories/)
  2. Sandmlink de 4 hook files desde source tree a ~/.quoth/hooks/
  3. Inandecta hook declarations en ~/.claude/settings.json (merge, no overwrite)
  4. Adds permission Bash(node .quoth/*)
  5. Shows instructions to start daemon
Idempotente: El script detecta si anda esta instalado and no duplica configuracion. Seguro re-ejecutar.
